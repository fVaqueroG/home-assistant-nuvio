# Nuvio wordmark header

The full-size Nuvio Lovelace card (including the same card within `custom:nuvio-popup-card`) uses the official Nuvio wordmark image in its header instead of the text heading. The version indicator and all existing controls remain in place. If the image cannot load, the configured text title remains visible as a fallback.

Official image: https://nuvio.tv/assets/nuvio-app-logo-wordmark.webp
